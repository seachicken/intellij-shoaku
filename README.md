## Why?

AI can generate code faster than we can understand it.
When understanding falls behind, reviews slow down, and maintenance risk grows.

This project exists to keep development human-paced, understandable, and owned.

## Requirements

This plugin uses Codex CLI under the hood. See [architecture.md](https://github.com/seachicken/intellij-shoaku/blob/main/docs/architecture.md) for details.

- [Codex CLI](https://developers.openai.com/codex/cli)
- Node.js 24 or later
