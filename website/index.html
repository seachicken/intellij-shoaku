What is Shoaku?

Shoaku is an open-source plugin for IntelliJ IDEA. It uses Codex CLI to investigate and implement a goal in a separate workspace while you work in your own.

How does it help with AI-assisted coding?

At the end of a task, Shoaku lets you compare your implementation with the agent's work. The comparison helps reveal trade-offs, gaps, and useful alternatives before you merge or ship.

What do I need to use it?

Install Shoaku from JetBrains Marketplace, then configure Codex CLI and Node.js 22 or later in your development environment.
